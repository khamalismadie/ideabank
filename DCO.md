(d) I understand and agree that this project and the contribution

    this project or the open source license(s) involved.

## Sign-off Procedure

To sign your commits, add the following line to each commit message:

```
Signed-off-by: Your Name <your.email@example.com>
```

This can be done automatically with:

```bash
git commit -s -m "Your commit message"
```

The `-s` flag adds the sign-off line automatically.

## Why DCO?

The DCO is a lightweight alternative to a CLA (Contributor License Agreement). It:

- Establishes that you have the right to submit the contribution
- Is used by Linux kernel, CNCF projects, and many others
- Does not require signing legal documents
- Is revocable (you can stop contributing at any time)
