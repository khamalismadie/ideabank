# PRD Backlog — Sprint

Sprint backlog derived from the product [PRD](../01-product/product-requirements.md) (user stories P0 / P1 / P2, phases MVP / V1 / V2 / V3).

## Sprint Goal

Deliver the MVP core loop: users can create, connect, and visualize ideas as a mindmap.

## Committed Backlog — Sprint 1 (MVP scope)

| ID      | User Story                                                            | Priority | Status    |
| ------- | --------------------------------------------------------------------- | -------- | --------- |
| PRD-001 | As a user, I can create an idea with title and description            | P0       | Committed |
| PRD-002 | As a user, I can connect ideas (parent / related / causes / inspires) | P0       | Committed |
| PRD-003 | As a user, I can visualize ideas as a mindmap                         | P0       | Committed |
| PRD-004 | As a user, I can edit and delete an idea                              | P0       | Committed |
| PRD-005 | As a user, I can search ideas by keyword                              | P0       | Committed |

## Open Backlog

| ID      | User Story                                                    | Priority |
| ------- | ------------------------------------------------------------- | -------- |
| PRD-006 | As a user, I can tag ideas (category / label)                 | P1       |
| PRD-007 | As a user, I can expand an idea with AI (generates sub-ideas) | P1       |
| PRD-008 | As a user, I can export mindmap (PNG, PDF, JSON)              | P1       |
| PRD-009 | As a user, I can filter by tag or time range                  | P1       |
| PRD-010 | As a user, I can collaborate on a mindmap                     | P2       |

## Sprint Cadence

- **Planning:** select committed backlog items into the sprint
- **Development:** TDD + Conventional Commits + feature branches
- **Review:** demo + PR merge
- **Retro:** improve process, update backlog
